# Architecture Decision Records

ADRs registram decisoes arquiteturais permanentes deste repositorio.

## Indice

- [ADR-0001 - Aplicacao principal em repositorio independente](0001-aplicacao-em-repositorio-independente.md)

## Convencao

Cada ADR deve conter contexto, decisao, consequencias e status. Decisoes substituidas permanecem no historico e recebem o status `substituido`.
